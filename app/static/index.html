Capabilities

Everything you need to work
with HL7 v2 messages

Built for engineers who need to trust the output.

Segment-level parsing

Every field, component, subcomponent, and repetition preserved exactly as received. Custom delimiters are read from MSH — not assumed.

PID→7 fields
PV1→19 fields
OBX→11 fields

Structural validation

ERROR / WARNING / INFO with field locations, explanations, and suggested corrections.

FHIR R4 Bundles

Patient, Encounter, and Observation resources mapped from PID, PV1, and OBX.

Patient Encounter Observation

ACK generation

MSH + MSA with AA, AE, or AR outcome — referencing the original control ID.

JSON & XML serialization

Documented, standards-aware output. JSON parseable by any JSON parser, XML well-formed and escaped.
